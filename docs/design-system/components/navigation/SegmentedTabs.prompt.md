Fully-rounded segmented control for a small set of mutually-exclusive options — onboarding's Postura/Parpadeo switcher, the sidebar's Claro/Oscuro theme toggle.

```jsx
<SegmentedTabs options={[{label:'Postura Corporal', value:'posture'}, {label:'Parpadeo Frecuente', value:'blink'}]} value={tab} onChange={setTab} />
```
